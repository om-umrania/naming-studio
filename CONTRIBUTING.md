# Contributing

Open an issue with the task, expected behavior, actual behavior, platform/version, and a sanitized example. Keep private naming briefs and credentials out of issues.

Edit canonical skills in skills/. Preserve sibling references, the three skill boundaries, dated evidence, and direct-call behavior. Update docs when behavior changes. Run ./scripts/check.sh; use docs/EVALUATION.md for behavioral review. Manifest versions must stay aligned. Document runtime testing separately from structural checks.
