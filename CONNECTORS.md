# Optional connections

The plugin bundles instructions only. It does not install an MCP server, request credentials, or guarantee that a service is available on every host.

- **Web research:** use the host's available browsing tools for current category/conflict research. Keep unresearched claims provisional.
- **Domain checks:** naming-domains discovers a connected Namecheap registration-check tool and its current schema. A user-authenticated Namecheap integration is optional; no connector IDs or tool names are assumed across platforms. If absent, use Namecheap public search when accessible, otherwise report not checked.
- **Project files:** a writable user workspace is needed to save and resume. Without file access, provide exportable content and disclose that persistence is incomplete.

No integration grants permission to buy domains, register marks, contact people, or publish customer projects.
